# KazanNeft

## ⛽ Landing Page de Empresa Fictícia (HTML e CSS)

O repositório **KazanNeft** contém uma *landing page* desenvolvida com **HTML** e **CSS** puro, simulando o website de uma empresa fictícia, possivelmente do setor de energia ou petróleo (dado o nome "Neft", que significa petróleo em russo). O projeto demonstra a capacidade de criar um design profissional e estruturado para um website corporativo, focando na apresentação de informações e na identidade visual.

### ✨ Destaques do Projeto

*   **Design Corporativo:** O layout e a estilização são voltados para um website de negócios, com seções claras e um visual limpo.
*   **HTML e CSS Puro:** O projeto é uma demonstração de habilidades fundamentais em desenvolvimento *frontend*, sem a dependência de *frameworks* ou bibliotecas JavaScript.
*   **Assets:** A presença da pasta `assets` indica o uso de recursos visuais (imagens, ícones) para compor o design da página.
*   **Estrutura Simples:** O código é direto e focado na implementação de um layout limpo e funcional.

### 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso Principal |
| :--- | :--- |
| **HTML5** | Estrutura e marcação semântica do conteúdo (58.5%). |
| **CSS3** | Estilização completa, incluindo layout, cores e tipografia (41.5%). |

### 📂 Estrutura do Projeto

O projeto segue uma estrutura de arquivos simples e direta:

```
KazanNeft/
├── .idea/          # Arquivos de configuração do ambiente de desenvolvimento
├── assets/         # Imagens, ícones e outros recursos visuais
├── index.html      # Página principal (Landing Page)
├── styles.css      # Folha de estilos principal
└── README.md       # Este arquivo
```

### 🚀 Como Visualizar

Para visualizar a *landing page*, basta clonar o repositório e abrir o arquivo `index.html` em seu navegador web:

```bash
# 1. Clone o repositório
git clone https://github.com/BrizidoAndre/KazanNeft.git

# 2. Navegue até o diretório do projeto
cd KazanNeft

# 3. Abra o arquivo index.html no seu navegador
# (Exemplo para Linux/macOS)
open index.html
# (Exemplo para Windows)
start index.html
```
